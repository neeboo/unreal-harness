What this does not measure

  • Not a public benchmark. This is not Terminal-Bench 4.0, DeepSWE 1.1, SWE-Atlas QnA, or ALE-CLI. Those need Harbor plus a container runtime; the design and the exact commands are in BENCHMARK.md.
  • Not "better than a bare harness". That comparison is dsh versus dsh plus these plugins on a public dataset. It is designed and not yet run.
  • Not the paper's full loop. The candidate pool here is hand-written strategies, so replay-based selection is exercised and an LLM proposing new policy code is not. That is the one step standing between this and the paper's claim.
  • No absolute number means anything alone. These are properties of a rolling-maximum task with a node evaluator. Only the comparison between arms is informative, and only because they are otherwise identical.
